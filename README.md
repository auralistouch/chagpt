# 实时行情断流修复

截图中的“币安指数行情响应中途断开或不完整”属于实时请求断流；此前断点重试只覆盖评估下载，此版补齐实时网页/手机使用的路径，策略与累计命中率标准不变。

- 实时时间和指数历史仅对超时、断流、无效JSON及408/500/502/503/504最多尝试3次，等待0.5/1.5秒；当前指数快照最多2次。451、418/429、证书错误、非法行情与磁盘错误不自动重试。
- 整个实时历史获取有60秒预算，避免逐页重试无限拖长。预算不足会暂停本次分析并保留完成页。
- 当前策略的实时指数历史页缩小至500根；每页价格、数量、时间严格校验后才保存。即使只有启动时的500根，也会在下次复用并补缺页。
- 重启可读回最新连续缓存作下载种子；它不是当前信号。只有补齐当前完整历史、取得新鲜指数快照并通过原策略条件后，才可能发方向提醒。失败不拿旧行情替代成功。
- 推送日志中的行情错误增加endpoint和attempt，便于区分时间、历史和快照请求阶段。
- 评估下载仍为原来的最多4次尝试，没有与实时重试叠加成12次。不会改变价格来源或绕过地区限制。

更新时停止旧终端、解压修复版并运行start.command，打开原来的本机网页；Bark地址和已完成的历史缓存沿用原配置目录。请先等自动获取/重试完成，再看最新错误记录。

## 固定的最新研究假设

主候选在测试结果之前固定为band_reentry，不根据另两个候选哪个分数高而切换。

1. 先出现20分钟均值±2倍总体标准差之外的收盘偏离。
2. 当前已收盘K线回到整个带内，并出现朝均值方向的反向实体；看涨收盘位于K线上方35%，看跌位于下方35%。
3. 近20分钟方向效率不超过0.35，EMA20/EMA50距离不超过1ATR，研究低效率、未明显单边伸展的环境。
4. 至少60根已收盘K线，ATR14/价格为0.02%–0.5%。上下方向镜像，不使用成交量。
5. 有效信号须收盘不足60秒、指数快照不足15秒，指数与信号收盘价偏差不超过0.5ATR。同一/相隔不足601秒不重复。

这些是研究假设，没有被证明能盈利。规则函数不读取未来，指标与输出数值均不解释为概率。

## 65%验收门槛如何工作

规则冻结点为 **2026-11-04 01:10（America/Los_Angeles，UTC-8）**，即UTC09:10。此前数据不进入新验收，继续记录为历史研究。

- 程序按冻结后的新指数历史生成固定候选，按全部方向的完整已结算样本统计。至少100个完整已结算研究样本，看涨和看跌合并累计；平价计入已结算总数但不算赢，未验证另列。这100笔是既有的研究样本基准，不是65%的定义。
- 累计命中率＝获胜次数÷全部已结算次数（含平价），达到65%才满足命中率条件；不再用Wilson下界、单笔预测概率或每个方向各自达标作门槛。10笔至少赢7笔、20笔赢13笔、100笔赢65笔均达到这一比例。研究样本不足仍等待；若命中率已达标但按净收益假设计算的净盈亏不为正，会由单独的收益条件拦截并显示原因。
- 通过也只表示该分钟参考实验的滚动条件满足；历史样本、市场变化、真实提交秒位和人工操作都使它不能保证未来累计命中率；累计65%也不是承诺每连续10笔固定赢7笔。程序永远不宣称guaranteed_win_rate。
- 网页、桌面/声音和手机各自核对当前版本及passed标记。服务未返回当前版本、验收数据缺失、过期、偏离或演示行情均不发送正式方向。
- 未达标时不会为凑次数放宽阈值。数量受条件、样本和冷却限制，没有保证每日几次。

新策略的指数历史在本机按UTC日保存，最多装入最近30天连续历史，重启后继续累计。若中断超过覆盖窗口产生缺口，不补造价格；仅使用最新连续尾段，并显示缺口诊断。损坏缓存不当有效样本。首次实时下载仍为3天，之后逐步累计；它不是宣称已积累100个新样本。历史文件只含公开指数，不含Bark密钥或账户。

## 评估和订单核算

`evaluate.command`仍保留断点下载、有限重试和成功后Finder定位报告。只评估当前策略，不再生成此前策略对比。CLI：

```bash
python3 evaluate.py --days 30
python3 evaluate.py --input work/pullback-evaluation.csv
```

默认报告 `work/pullback-evaluation.json`，只包含当前版本、历史单点研究和冻结后的验收进度。已看过的旧窗口不会变成独立新样本。断点缓存固定原时间窗口；需要新窗口可用 `--refresh`，不会删旧缓存。报告不代表真实订单，也不自动修改参数。

订单CSV工具仍只在本机核算、不保存或外发，刷新后清除。格式：

```text
order_id,direction,open_time_ms,expiry_time_ms,open_index,close_index,net_payout,stake
```

方向UP/DOWN，时间整数毫秒且开仓至到期600秒；net_payout为该笔净收益比例（如0.8），stake为本金。缺失端点留空记未验证，不计亏；重复或非法记录拒绝整份文件。工具格式需要按订单映射列名，不保证币安导出原文件能直接导入。
