# 比特币十分钟观察台 · v1.2

中文网页现货行情研究工具。默认使用 **Coinbase BTC/USD** 独立公开数据，研究十分钟价格方向，显示“观察看涨 / 观察看跌 / 等待”、判断依据、最近三小时走势及模拟结果。**不提供事件合约交易、不自动下单、不需要账户或 API 密钥，没有已经证明的盈利优势。**

## 从旧版本更新（Mac）

1. 在旧的 `start.command` 终端窗口按 Control+C 停止程序。
2. 从 GitHub 的 `codex/btc-ten-minute-signals` 分支重新 Download ZIP，解压到一个新文件夹，避免与旧版混淆。
3. 双击新文件夹的 `start.command`，再刷新浏览器。页头应显示 v1.2，默认来源为 Coinbase BTC/USD；继续使用币安时，请在下拉框手动选择币安来源。
4. 点击“获取分析”；首次约三天数据需分批下载。成功后可选每 30 秒刷新，之后只追加新数据。

这是独立的现货研究模式，不是转发、镜像或规避币安访问限制的方法。不能恢复你在不支持地区使用币安事件合约的资格。请遵守各数据源及产品所在地要求；Coinbase 接口在你本机是否可达，需要实际请求确认。

## 自动刷新与断连（v1.2）

勾选自动刷新后，每次请求完成再等待 30 秒发出下一次请求，不重叠发起请求。失败后自动按 5、10、20、40、60 秒间隔重试，成功后恢复正常间隔；取消勾选立即停止后续重试。切换回页面或系统报告网络恢复时，也会尝试刷新。状态文字显示下一次重试间隔，网页在后台可能被浏览器延后执行。

币安和 Coinbase 的后续请求都尽量复用已下载的连续行情，只补充新数据，避免每次刷新重新下载三天数据。初次运行或缓存失效仍需完整下载。

连接失败或更新期间，方向提示暂停。若保留上次成功的数据，会明确标记为历史记录，不能作为当前买点；超过 90 秒的行情也会撤下方向。自动重试不会保证外部网络恢复，不会切换行情源或绕过地区限制。

旧版显示 `Failed to fetch` 通常表示浏览器未收到本机服务的有效响应，截图本身不能定位具体原因。新版区分本机连接失败、请求超时、行情服务错误及本机处理错误。如果持续失败，确认 `start.command` 终端仍在运行、Mac 未睡眠；将终端最新错误发给协助人员。不要仅凭这条错误认定币安接口故障。

## 不会代码怎么使用

需要 Python 3.10 或更新版本。无需安装第三方依赖。

- Windows：从 python.org 安装 Python，下载并解压本项目，双击 `start.bat`。保持窗口打开，在浏览器地址栏输入 `http://127.0.0.1:8000`。
- macOS：安装 Python 后，双击 `start.command`，保持终端窗口打开，在浏览器地址栏输入同一地址。若系统阻止双击启动，可在项目文件夹打开终端运行 `sh start.sh`。
- Linux：在项目文件夹打开终端运行 `sh start.sh`，然后在浏览器地址栏输入同一地址。
- 页面默认选择“Coinbase BTC/USD（行情研究）”，点击“获取分析”。中间 80% 是**模拟净收益比例**，仅用于假设二元收益的数学研究，不是 Coinbase 的报价、投资收益或可交易产品。若只看走势，可保持默认值；它影响模拟门槛，不影响价格数据。
- 首次获取约三天数据需要一些时间。需要持续观察时勾选“每 30 秒刷新”。行情超过 90 秒会撤下方向提示。
- 未连通行情时，选择“合成演示”熟悉页面。人工生成的数据始终显示等待，其数值**不是**真实历史表现。
- 关闭启动窗口，或终端按 Ctrl+C，停止程序。默认只监听本机，请不要把没有认证的服务直接暴露到互联网。

本云环境可运行 `cd /workspace/chagpt && python3 app.py`。云环境是否提供可访问的网页入口取决于所在产品；本项目不会自动部署或发布网站。

## 信号和胜率

五项条件必须同时通过：EMA20/50 趋势分离、RSI14 简单均值动量、相对成交量、ATR14 波动范围、短期方向及均线距离。这些是固定启发式规则，不是经过盈利验证的预测模型。满足条件的个数不是概率；没有机会就等待。

默认行情来自 Coinbase Exchange `https://api.exchange.coinbase.com` 的 `/time` 和 `/products/BTC-USD/candles`，品种 BTC-USD，粒度 60 秒。每页最多 300 根，按时间排序并校验连续性，不补造缺失价格。后续刷新重用已下载数据并追加新 K 线。Coinbase BTC/USD 与币安 BTC/USDT 不同，不能把一个来源的模拟结果当成另一个来源的表现。

保留的“币安 BTC/USDT（须当地支持）”来源使用 `https://api.binance.com` 的公开现货接口，供当地及账户获支持时使用；不支持时请使用独立研究模式。所有来源只分析已收盘且连续的 K 线，网络错误、行情缺失或过期时停止方向提示，失败不自动切换其他来源或演示数据。

约三天行情按时间分成前 2/3 描述段、后 1/3 验证段，不用后段调参。信号在收盘后产生，下一分钟开盘价模拟入场，第十分钟收盘价模拟结算；持仓不重叠，未结算交易不计入结果。每笔固定投入 1 单位，胜出记净赔率收益，失败记 -1，平价保守记 -1。费用、报价差异、执行延迟未计入。

观察方向还需满足：后段至少 30 笔已结束交易，胜率 95% Wilson 区间下界大于 `1 / (1 + 净收益比例) + 2%`。例如净收益 80%，理论盈亏平衡胜率为 55.56%，门槛为下界超过 57.56%。可能长时间没有提示，这是预期行为。

**这些过滤条件不证明高胜率或正收益。** 三天样本很短、市场会变化，交易结果可能相关，统计区间也可能偏乐观；频繁查看回测不等于独立验证。请先长期模拟和前向观察，不要根据演示结果投入资金，不要亏损后翻倍加仓。

## 与事件合约的差异

本工具**没有连接任何事件合约报价、交易或结算接口**，不提供受限制地区的事件合约使用能力。现货方向回测不等于事件合约真实胜率。具体条款、结算价格来源、周期、平价处理及赔率需要另行核实。Coinbase BTC/USD 研究不能替代币安 BTC/USDT 结算或实际可成交买点。

## 开发与验证

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js  # 可选；运行程序不需要 Node.js
python3 tests/browser_refresh.py  # 可选；开发环境需安装 Playwright 和 Chromium
python3 app.py --port 8000
```

测试包含因果指标、十分钟结算、分段不跨界、不重叠交易、平价、回撤、异常行情、过期和演示抑制、分页、失败缓存及网页 HTTP 接口。HTTP 测试需要允许本机回环连接。

`strategy.py` 为策略和回测，`market.py` 为公开行情，`app.py` 为标准库网页服务，`web/` 为前端。`/health` 仅表明服务存活，不表明行情可用。

在自己的 Mac 上运行时使用本机网络，与云环境白名单无关。在云环境运行 Coinbase 研究模式需网络允许 `api.exchange.coinbase.com` 的 HTTPS 请求；币安模式需要 `api.binance.com` 且当地获支持。保持平台代理和 TLS 验证，不绕过白名单或地区限制。
