# BTC十分钟观察台 · precision_v6.0

网页只显示“多周期指数共识研究”。按用户最新要求，以改善每次选点准确性为目标，删除累计胜率目标、历史获胜次数准入和信号次数配额。保留网页、声音、桌面和Bark手机提醒，不自动下单。

## 当前如何选点

只使用已收盘的BTCUSDT指数OHLC：1/3/5/10/20/60分钟动量、EMA20/50/120差异、RSI、方向效率、短长波动比、K线实体与收盘位置，共18项固定因果特征。两个不同结构的模型分别判断方向：浅层梯度提升树、浅层随机树集合。

只有两个模型方向一致，且各自方向强度均超过冻结的筛选阈值时，才输出看涨或看跌；分歧或强度不足时等待。界面强度显示为“分数/阈值”，不是某一笔交易的成功概率。没有过去若干笔获胜达到某比例才能推下一笔的条件；历史结果只用于事后评价，不决定下一笔是否获准。

模型和阈值固定，不在用户运行时根据最近胜负自动改方向、调参或重训。不使用现货成交价、标记价、成交量或别的交易所价格替代指数。

## 实际研究成绩与限制

同一份43,200根用户提供的指数分钟数据：前15天训练、接着5天选强度阈值、后10天冻结评估。训练/校准期不当后续业绩，标签边界净化12分钟。共识90/95/98分位三种筛选阈值只依据校准记录选择，后10天不参与选择。本次选定各模型校准强度95分位；它是分数排序位置，不是胜率。

后10天实际选出的完整参考记录：**107次，60胜47负，累计56.07%**；赢+0.8、输-1的假设净盈亏+1.0单位。原ATR候选同段407次221胜54.30%、-9.2单位。新方案只是探索中略有改善，不能宣称已经证明每笔更准或稳定盈利。

后两个5天命中率54.35%/57.38%；四段2.5天中有一段仅35.71%。校准的40/58=68.97%不是后10天成绩，不能拿它宣传。数据已被多次检视，所有结果都属探索；不能替代冻结规则后的新行情验证。完整结果见 `consensus_research.json`、当前模型可重算结果见 `consensus_evaluation.json`。

固定模型以校验过的JSON压缩文本保存，程序用Python标准库推理，无需安装NumPy或机器学习软件。移植与原研究程序逐行比较43,080个可用特征行，无信号翻转；另有独立重新拟合的测试基准。模型文件缺失或校验失败会停止分析，不回退旧策略。

## 信号时间与结算

识别当前已收盘信号后发送提醒。参考入场＝信号时间后1分钟，参考到期＝参考入场后10分钟。推送可能延迟，因此不保证收到后有完整1分钟准备。未来入场和到期指数未知；当前快照不是未来开仓价。

[币安事件合约FAQ](https://www.binance.com/en/support/faq/detail/172247f1c4b8401ab106fb63900f3825)：实际订单提交后下一秒取开仓指数，再计600秒到期；平价退本金。实际净赔付动态变化、以订单确认为准。历史表采用各自分钟K线open的两个单点，只研究固定时程，不能重建任意秒位提交的订单。

指标须收盘后不足60秒、快照不足15秒；错源、演示、过期与不完整数据不发方向。同一或相隔不足601秒不重复。首次模型计算在获取新快照之前完成，随后分析耗时也计入时效，不用过期价格追发。

累计命中率＝获胜次数÷全部已结算次数；平价退款计入总数但不算赢，缺失和待到期另列。真实订单与分钟参考研究分开；CSV导入工具只在本机核算，不登录币安验证来源，也不据导入结果自动调参。

## 启动和迁移

1. 旧程序终端按Control+C停止，完整解压新版，双击 `start.command`。需要Python3.10+，模型文件 `consensus-models.b85`须与程序放在同一文件夹。
2. 打开 http://127.0.0.1:8000 ，确认页头为 `precision_v6.0`。若8000已被占用，先停止原程序。
3. 原v4/v5 Bark地址、启用状态、净收益假设、去重时间和未知配置字段保留并迁移。保存失败会提示，不能静默重置冷却。
4. 手机设置中地址留空表示保留。发送测试确认手机展示；首次桌面通知和声音需浏览器授权，主动停用设置会记住。
5. 网页关闭后手机后台可继续，但Mac程序须运行、联网且唤醒；合盖、休眠或退出会停止监测。

最近12小时只统计实际候选、发送尝试、Bark接受/拒绝/未知，不设置配额。测试不计入，accepted只指服务接受，不代表手机已显示。记录不足或保存异常明确标记不完整，不自动重发结果未知的同一信号。

配置默认 `~/.config/btc-observer/phone.json`，可用 `BTC_OBSERVER_CONFIG_DIR`指定。最新日志、计数和指数历史使用 `latest_v6`目录，不混入旧策略记录。只在本机回环地址服务，不部署云端；地区451问题未被解除，不绕过限制。
