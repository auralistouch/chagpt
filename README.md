## 命中率口径

累计命中率＝获胜次数÷全部已结算次数。10次赢7次是70%，20次赢13次是65%。平价退本金但不算赢；待到期与缺失另列。这里从未把65%作为某笔预测成功概率。

研究结果与真实订单分开：一分钟指数open参考实验不能重建任意秒位提交的订单。实际胜率须用对应订单的开仓指数、到期指数和赔率核算；本机CSV导入工具不登录币安核验来源。

## 启动与更新

1. 在旧程序终端按Control+C停止，解压新版，双击 `start.command`。需要Python3.10+，主程序只依赖标准库。
2. 打开 http://127.0.0.1:8000 ，确认页头显示 `activity_v5.0`。8000被占用时先停止旧程序再启动。
3. 原Bark地址、启用状态、净收益假设、去重时间和未知配置字段自动保留并迁移到最新版。保存失败会提示，不能静默重置冷却。
4. 点击手机测试确认实际展示。首次网页声音和桌面通知需授权；主动停用与刷新设置会被记住。
5. 关闭网页后手机监测可继续，但Mac程序须运行、联网且唤醒；休眠、合盖或退出会中断。

配置默认 `~/.config/btc-observer/phone.json`，可用 `BTC_OBSERVER_CONFIG_DIR`指定。程序只在本机回环地址服务，不部署云端。云端451地区限制未被解除；本版不绕过限制。

实时断流有限重试、分页校验、已完成页缓存与跨重启续传保留。失败不会用旧行情假装成功，分析耗时也计入时效判断。

## 官方规则与数据边界

[官方指数K线接口](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data#index-price-klinecandlestick-data)最小1分钟，字段[5]为Ignore。现货秒K线、合约成交价和标记价格不等于事件合约指数。工具不能读取用户资格、实际订单或逐笔赔率。
